# FIRST_PROJECT

A responsive HTML/CSS menu page demonstrating modern web design principles.

## Overview

This project showcases a responsive menu layout with three food categories (Chicken, Beef, and Sushi). The design adapts to different screen sizes using CSS media queries, providing an optimal viewing experience on desktop, tablet, and mobile devices.

## Features

- **Responsive Design**: Automatically adjusts layout for desktop (3 columns), tablet (2 columns + 1 full-width), and mobile (single column)
- **Clean UI**: Modern styling with colored category labels and consistent spacing
- **Cross-browser Compatible**: Works on all modern browsers

## File Structure

```
FIRST_PROJECT/
├── README.md
└── site/
    └── index.html    # Main responsive menu page
```

## Usage

Simply open `site/index.html` in your web browser to view the responsive menu page.

### Viewing the Page

1. Clone this repository
2. Navigate to the `site` directory
3. Open `index.html` in your preferred web browser

### Testing Responsiveness

Resize your browser window to see the layout adapt:
- **Desktop (≥992px)**: Three columns side by side
- **Tablet (768px-991px)**: Two columns on top, one full-width below
- **Mobile (<768px)**: Single column stack

## Technologies Used

- HTML5
- CSS3 (with media queries for responsive design)
